## Architecture decisions and items considered & deferred

- **Vector Database / Embeddings (pgvector / Pinecone)**: Rejected for MVP in favor of direct prompt context injection. Small business policies rarely exceed 50–100 items. Direct injection guarantees 100% recall, eliminates embedding drift, avoids synchronization pipelines, and fits easily into modern LLM context windows (200k tokens).
- **Stripe Billing Integration**: Deferred to post-MVP stretch goal. Quotas are enforced at 50 drafts/month per workspace in the database with 429 status codes and UI warning banners.
- **Tone Customization Custom Prompts**: Replaced with 4 tested preset tones ("Professional", "Friendly", "Direct & Concise", "Empathetic") to keep output consistent and avoid user prompt injection vulnerabilities.
